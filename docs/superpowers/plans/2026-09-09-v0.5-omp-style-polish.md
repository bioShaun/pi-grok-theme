# v0.5 omp-style polish Implementation Plan

> I'm using the writing-plans skill to create the implementation plan.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship vars-first Pi themes, omp-flavored footer chrome (presets/glyphs/separators), OSC 8 path + git counts, and a dual Pi/omp theme export as version `0.5.0` across four sequential PR branches.

**Architecture:** A Node ESM generator (`scripts/build-themes.js` + `scripts/theme-src/*`) owns the shared palette and overlays and emits committed `themes/*.json` (Pi load path) plus, in R4, `themes/omp/*.json` (omp extras only). Runtime stays Pi-extension-local: `settings.ts` persists prefs with migration, `glyphs.ts` adds density selection, `footer.ts` owns fitting/OSC8/git counts, and `chrome-theme.ts` continues to map only existing Pi semantic tones — no fake `statusLine*` tokens on Pi themes.

**Tech Stack:** TypeScript ESM extension for Pi Coding Agent (`@earendil-works/pi-coding-agent` / `pi-tui` peer deps), Node test runner (`node --test`), `tsc --noEmit`, Node `fs`/`child_process` (no new runtime deps), committed JSON themes.

## Global Constraints

- Package version stays `0.4.1` (`package.json` + `version.ts`) through R1–R3; bump to `0.5.0` only on R4 (or the release PR that lands R4).
- CHANGELOG: add/expand `## Unreleased` notes on R1–R3; fold into a single `## 0.5.0` section when R4 lands.
- Branch family from `main`: `v0.5-r1-vars-themes` → `v0.5-r2-footer-visual` → `v0.5-r3-osc8-git-counts` → `v0.5-r4-omp-export` (sequential PRs; do not push unless the human asks).
- No new runtime npm dependencies; generator is Node ESM only.
- Pi themes under `themes/grok-build*.json` must remain schema-clean (no `pythonMode`, no `statusLine*`); omp extras live only under `themes/omp/`.
- `package.json` `pi.themes` continues to list only `./themes/grok-build-coding.json`, `./themes/grok-build.json`, `./themes/grok-build-day.json`.
- Preserve quality gates every PR: `npm run typecheck`, `npm test` (99+ cases), `npm run previews` deterministic, existing worktree/`gitdir` tests green.
- `chrome-theme.ts` contract unchanged: tones only (`success` / `warning` / `error` / `muted` / `accent` / …) — no new fake token names.
- Design source of truth: `docs/superpowers/specs/2026-09-09-v0.5-omp-style-polish-design.md`.

- [ ] **Step 4: Implement `scripts/build-themes.js`**

```js
#!/usr/bin/env node
import fs from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";
import { paletteDark } from "./theme-src/palette-dark.js";
import { paletteDay } from "./theme-src/palette-day.js";
import { overlayBase } from "./theme-src/overlay-base.js";
import { overlayCoding } from "./theme-src/overlay-coding.js";
import { overlayDay } from "./theme-src/overlay-day.js";

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");
const SCHEMA =
  "https://raw.githubusercontent.com/earendil-works/pi/main/packages/coding-agent/src/modes/interactive/theme/theme-schema.json";

function buildPiTheme(palette, overlay) {
  const vars = { ...palette, ...(overlay.varsExtra ?? {}) };
  return {
    $schema: SCHEMA,
    name: overlay.name,
    vars,
    colors: { ...overlay.colors },
    export: { ...overlay.export },
  };
}

function writeTheme(relPath, theme) {
  const abs = path.join(ROOT, relPath);
  fs.mkdirSync(path.dirname(abs), { recursive: true });
  fs.writeFileSync(abs, `${JSON.stringify(theme, null, 2)}\n`, "utf8");
}

const themes = [
  ["themes/grok-build.json", buildPiTheme(paletteDark, overlayBase)],
  ["themes/grok-build-coding.json", buildPiTheme(paletteDark, overlayCoding)],
  ["themes/grok-build-day.json", buildPiTheme(paletteDay, overlayDay)],
];

for (const [rel, theme] of themes) writeTheme(rel, theme);
console.log(`Wrote ${themes.length} Pi themes`);
```

Add npm script in `package.json`:

```json
"build:themes": "node scripts/build-themes.js"
```
